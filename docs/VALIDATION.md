# v0.3.1 验证记录

日期：2026-10-20。设备型号：`xiaomi.airc.h61h00`、`dmaker.fan.p28`。

已实际下发控制，并用云端属性回读与 App 界面核对：

| 设备 | 验证项目 | 结果 |
|---|---|---|
| 空调 | 开机、目标温度、模式、风速、左右摆风、上下摆风 | 通过 |
| 循环扇 | 开机、模式、档位、无级风速、左右/上下摆风、两个方向的摆风角度 | 通过 |
| 状态跟踪 | 实际出现首次回读旧状态，后续只读查询使“待确认”变成已确认 | 通过 |
| 周期刷新 | 独立接口改变风速，App 无需点击刷新即可更新 | 通过 |

以上是控制请求、设备云端回读和 GUI 显示层面的验收，没有目视确认机械运动，也没有测量制冷效果。Intel 真机、其他账号及其他电脑仍未验证。

测试前保存原始设置，测试后逐项读取并恢复，最终两台设备均为关闭状态。原始设备标识、账号信息和家庭设置未上传。

## 已确认的设备约束

- 模式切换可能联动改变温度、节能或其他参数，恢复时须逐项比对完整快照。
- 该循环扇的档位与无级风速联动，不能把两者视为独立恢复目标；冲突时需要用户选择主参数。
- 风扇在关机状态下可能拒绝档位写入；不能以已提交代替已回读确认。
- 不能承诺初始云端缓存中相互不一致的参数组合能够同时写回。

离线测试另有 36 项回归检查，不联网、不使用真实账号或设备。
