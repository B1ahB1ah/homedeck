# 参考资料

本项目使用 Swift 实现扫码登录、云端通信与设备属性映射。以下公开项目用于核对协议或接口形式，当前应用不运行其 Python 代码：

- [Do1e/mijia-api — apis.py](https://github.com/Do1e/mijia-api/blob/main/mijiaAPI/apis.py)：米家扫码流程、家庭/设备和手动场景接口。
- [Squachen/micloud — miutils.py](https://github.com/Squachen/micloud/blob/master/micloud/miutils.py)：小米云请求签名、随机数及 RC4-drop1024 协议核对。
- [XiaoMi/ha_xiaomi_home — miot_spec.py](https://github.com/XiaoMi/ha_xiaomi_home/blob/main/custom_components/xiaomi_home/miot/miot_spec.py)：公开 MIoT 规格读取与解析参考。

产品名称和商标属于各自所有者；家控台与上述项目、Apple 或小米没有官方隶属关系。
