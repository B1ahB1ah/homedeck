# 家控台 · HomeDeck

在 Mac 的 Touch Bar 和菜单栏控制米家设备、调用手动场景。使用自己的手机米家扫码登录，选择家庭后自动发现设备。

**当前版本：v0.3.1 测试分享版。** [下载安装包](https://github.com/B1ahB1ah/homedeck/releases/tag/v0.3.1) · [使用说明](docs/使用说明.txt)

## 功能

- 独立扫码登录，登录信息保存在 macOS 钥匙串；无需电脑安装米家。
- 选择家庭，按账号与家庭分别保存常用设备。
- 常用、灯光、温控、场景四个页面；提供开关、亮度、色温；按 MIoT 规格提供温控与摆风等属性。
- Touch Bar 全局小房子入口，设备详情与属性控制；无 Touch Bar 时可用主面板和菜单栏。
- 关闭窗口后常驻，可在菜单栏选择登录时启动。
- 打开面板或 Touch Bar 时立即查询状态；前台每 10 秒、后台每 60 秒刷新。操作后最多约 25 秒继续查询，明确区分待确认与已回读；控制命令不自动重复发送。
- 手动场景先预览，再确认执行。

## v0.3.1 更新

- 修复仅在控制后回读一次、云端延迟时界面长期停留旧状态的问题；后续自动查询只读状态，不重复下发控制。
- 补齐独立 `fan-control` 服务：空调风速、上下/左右摆风、送风方式、叶片定格；支持设备返回的节能、辅助加热、干燥、睡眠和指示灯开关。
- 循环扇增加摆风、摆风角度；已核对型号的无级风速、定时关机、立体摆风和关机回正也可用。
- 电暖器增加加热档位、定时与显示屏；环境温度、湿度等只作读取。
- Touch Bar 增加布尔属性开/关及多档位分页，温度可精确加减。
- 36 项离线回归检查包含模拟云端延迟、只读属性拒绝写入、工程配置排除；实际新增控制写入仍待用户试用验收。

## 运行要求

- 构建目标 macOS 13 及以上，安装包同时包含 Intel x86_64 和 Apple Silicon arm64。
- 目前仅支持米家中国大陆区账号及部分标准设备属性，需要联网访问小米云。
- 不依赖 Python、快捷指令、Tailscale、Home Assistant 或本机米家缓存。

## 使用

1. 从 [Releases](https://github.com/B1ahB1ah/homedeck/releases) 下载安装包，解压并将 App 放入“应用程序”。
2. 点击“扫码登录”，用手机米家右上角“+ → 扫一扫”，在手机上确认。
3. 选择家庭，等待目录和状态同步；设备卡片上的星标用于加入常用。
4. 关闭窗口后，从菜单栏或 Touch Bar 小房子入口唤出。
5. 在“家庭与账号”中可以切换家庭、续期登录或退出账号。

当前安装包只有 ad-hoc 本地签名，**尚无 Developer ID 签名和 Apple 公证**。其他电脑可能拦截首次打开；如遇拦截，反馈具体提示或等待正式签名版，不要关闭系统整体安全保护。重建或更新临时签名版本可能需要重新允许访问 App 自己的钥匙串登录项。

## 从源码构建

安装 Apple Command Line Tools，在仓库根目录执行：

```sh
./src/test.sh
./src/build.sh
```

构建脚本会生成 `家控台分享版.app`，并验证本地签名。测试脚本运行 36 项离线检查，不联网、不读取账号、不操作设备。

## 代码结构

| 文件 | 用途 |
|---|---|
| `src/Cloud.swift` | 扫码登录、登录续期、钥匙串、云请求签名与加密 |
| `src/Devices.swift` | 家庭目录、公共 MIoT 规格、通道映射、属性控制与场景 |
| `src/Models.swift` | 账号/家庭切换、收藏、定时刷新和界面状态 |
| `src/Onboarding.swift` | 扫码与家庭选择界面 |
| `src/Views.swift` | 主控制面板 |
| `src/TouchBar.swift` | Touch Bar 交互 |
| `src/TouchBarBridge.m` | 运行时检查全局 Touch Bar 私有接口 |

## 验证范围与限制

- 在一台 Apple Silicon Mac、macOS 26.5.2 上验证了独立扫码登录、家庭选择和钥匙串登录恢复。
- 已验证一个账号下 15 个设备的电源状态读取和 12 个手动场景的目录读取；v0.3.1 原生分享版未做新的设备写入或场景执行验收。
- 已完成双架构构建；Intel 真机、其他账号和其他电脑尚待验证。
- 云端回读表示云端报告的状态，不等于现场物理确认。
- 未识别规格的设备不会生成控制按钮；场景摘要受米家返回数据限制。
- 本项目不是小米官方客户端。扫码和云端接口、Touch Bar 私有接口未来可能变化。
